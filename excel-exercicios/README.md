# Excel - Exercícios

Exercícios de Excel que faço semanalmente para praticar. São exercícios de estudo, com dados fictícios.

## Assuntos praticados


- Funções SE, SOMASES e CONT.SES
- PROCX, PROCV, INDICE + CORRESP
- Subtotal
- Função FILTRO
- Tabelas dinâmicas
- Segmentação de dados
- Formatação condicional
- Porcentagens
