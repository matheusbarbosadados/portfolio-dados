###### **CRIAR 30 ARQUIVOS**



Script que cria 30 arquivos Python numerados de uma só vez, do 1.py ao 30.py.



###### **ARQUIVOS**



**01_criar_arquivos.py** - cria os arquivos 1.py até 30.py na pasta



###### **COMO USAR**



1. Coloque o script na pasta onde os arquivos devem ser criados.
2. Abra o script e clique no ícone de executar.
3. Aguarde a mensagem "30 arquivos criados com sucesso!" no terminal.



###### **COMO FUNCIONA**



1. Repete um laço de 1 a 30.
2. Em cada volta, cria um arquivo com o número como nome (1.py, 2.py, 3.py...).
3. Escreve em cada arquivo uma linha de comentário com o nome dele.
4. No final, mostra a mensagem de conclusão no terminal.



###### **BIBLIOTECAS**



Nenhuma instalação necessária. Usa apenas recursos do próprio Python.



###### **LIMITAÇÕES**



- Se já existir um arquivo com o mesmo nome, ele é substituído e o conteúdo antigo é perdido.
- Os arquivos são criados na pasta de onde o script é executado.
- A quantidade (30) e o formato do nome são fixos no código.
