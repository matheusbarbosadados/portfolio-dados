Passo 1: Abra o arquivo **1\_tratar\_dados.py** no VS Code.

Passo 2: Clique no ícone de executar.

Passo 3: Na janela que abrir, escolha a planilha (.csv ou .xlsx) e clique em Abrir.

Passo 4: Leia o relatório que aparece no terminal. Ele mostra o que foi corrigido e quais linhas têm alerta.

Passo 5: Abra o resultado na mesma pasta da planilha original: arquivo com **final \_limpo.xlsx** (abre com dois cliques) ou **\_limpo.csv**. Filtre a coluna alerta para ver só as linhas que precisam de conferência.



**ATENÇÃO:**



O arquivo original nunca é alterado. O resultado sempre vai para arquivos novos.

Se a janela de escolha não aparecer, procure na barra de tarefas do Windows. Às vezes ela abre atrás do VS Code.

Para abrir o **\_limpo.csv** no Excel, use **Dados > De Texto/CSV**, com **origem UTF-8** e **delimitador Vírgula**.
