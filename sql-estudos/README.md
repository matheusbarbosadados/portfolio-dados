# SQL - Estudos

Estudos de SQL com MySQL. Os exercícios usam um banco de dados fictício de uma loja de informática, com as tabelas `produtos` e `pedidos`.

## Arquivos

| Arquivo | Descrição |
|---|---|
| exercicios_mysql.sql | Criação das tabelas, dados fictícios e as 22 consultas dos exercícios |
| apostila_sql_1.pdf | Apostila com 11 exercícios |
| apostila_sql_2.pdf | Apostila com 11 exercícios |

## Assuntos praticados

- CREATE TABLE, INSERT, UPDATE e DELETE
- ALTER TABLE
- SELECT com WHERE, ORDER BY e LIMIT
- Filtros com IN, BETWEEN e LIKE
- Funções COUNT, SUM, AVG, MIN, MAX e FORMAT
- GROUP BY e HAVING
- VIEW
- INNER JOIN

## Como usar

1. Abra o arquivo exercicios_mysql.sql no seu programa de MySQL.
2. Execute os comandos na ordem, de cima para baixo.
